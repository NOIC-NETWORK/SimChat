# 05 IDE 界面速览

> 本章属于「只使用」路径（A），前置：[03 配置工作目录与第一次对话](03-workspace-and-chat.md)。

## 1. 你会得到什么

浏览器打开 `http://127.0.0.1:5000/ide`，看到六区布局：菜单栏、活动栏、侧栏、中央编辑器、右侧对话面板、底部控制台。能打开工作目录里的文件查看内容，能在同一屏里发消息、看工具调用事件与日志。

```text
┌ 菜单栏 File Edit View Run Terminal Help ────────────────┐
│ 活动栏 │ 侧栏（文件树） │ 中央编辑器（只读） │ 对话/检查器 │
│  ℹ️    │ src/           │ 1  import os      │ 你：……      │
│  ...   │   main.py      │ 2  ...            │ SimChat：…… │
├────────┴────────────────┴───────────────┴─────────────┤
│ 底部控制台  事件流 │ 沙箱输出 │ 日志                        │
├────────────────────────────────────────────────────────┤
│ 状态栏  就绪 · 服务商 · 模型 · 模式 · 审批 · 工作目录      │
└────────────────────────────────────────────────────────┘
```

## 2. 前置条件

- 服务商可用、工作目录已选（第 02、03 章）。
- 建议准备一个有几层子目录的代码目录，方便观察文件树。

## 3. 跟着做

### 3.1 进入与退出

- 进入：主界面右上角「在 IDE 中打开项目」按钮，或直接访问 `/ide`。
- 退出：活动栏最下方「返回对话界面」（← 图标），回到 `/`。
- IDE 与对话界面共用同一后端、同一份配置与会话数据，不是两套系统。

### 3.2 六个区域各是什么

| 区域 | 位置 | 现在能做什么 | 状态 |
|---|---|---|---|
| 菜单栏 | 顶部 | File / Edit / View / Run / Terminal / Help 下拉；中间是命令面板入口 | 可用 |
| 活动栏 | 最左竖条 | 资源管理器、搜索、Agent 与会话、扩展、调试、设置；底部还有切右侧面板、切主题、返回对话 | 可用 |
| 侧栏 | 活动栏右侧 | 随活动切换：文件树 / 搜索 / 会话列表 / 方块与工具 / 设置导航 | 部分占位（见 3.4） |
| 中央编辑器 | 中间 | 打开文件、标签页切换、行号显示 | **只读**，不能编辑保存 |
| 右侧面板 | 右侧 | 对话（与同一模型聊天）、检查器（当前会话、运行、用量） | 可用 |
| 底部控制台 | 中下 | 事件流、沙箱输出、日志三个页签，可清空 | 可用 |
| 状态栏 | 最底 | 状态灯、服务商、模型下拉、模式、审批、工作目录、Panel/对话开关 | 可用（审批为本地显示） |

### 3.3 打开一个文件

1. 活动栏点「资源管理器」（或 `Ctrl+1`）。
2. 文件树里点目录展开/收起，点文件直接在中央打开；顶部出现标签，点 `×` 关闭。
3. 预期：左侧行号，右侧内容。中文按 UTF-8 → GBK → UTF-16 → Latin-1 依次尝试解码。

**注意**：编辑器目前是只读快照，光标不能落进去，也没有保存。要改文件，用 Agent 模式让它调用 `file_edit` / `file_write`（第 04 章），或者自己去别的编辑器改。

### 3.4 认清哪些面板是占位

- **搜索**（`Ctrl+2`）：显示「全局搜索 API 未接入」——**未实现**，不要期待能搜内容。
- **调试**（`Ctrl+5`）：显示「调试面板占位」——**未实现**。
- **扩展**（`Ctrl+4`）：是真的，列出 `.simchat/mods/` 的 MOD 与当前 Agent 工具清单，带风险标签（只读/写入/高风险）。右侧开关当前只会上报「启用」，**不能用来停用**；停用请去控制台的技能页（第 07 章）。
- **设置**（`Ctrl+6`）：只有四个跳转项（服务商与模型 / 对话参数 / 工作目录 / 外观），点下去进入的是同一套设置面板，不是 IDE 专属设置。

### 3.5 右侧对话与底部控制台

- 右侧「对话」页签：输入框下方提示 `Ctrl+Enter` 发送；上方有「对话 / Agent」模式切换（与主界面的开关等价）。
- 右侧「检查器」页签：显示当前会话 id、模型、模式、审批策略、本次运行的步骤数、token 用量与最近事件。
- 底部「事件流」：按事件类型着色（plan / thought / tool_call / tool_result / approval / final / error），是排查「模型到底做了什么」最快的地方。
- 「沙箱输出」和「日志」：前者是 MOD 子进程的输出，后者是服务端日志的镜像（磁盘上是 `.simchat/data/logs/simchat.log`）。
- 清空：`Edit` 菜单里的四个「清空…」项，或 `Terminal` 菜单的「清空当前面板」。

### 3.6 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Shift+N` | 新建会话 |
| `Ctrl+K` | 打开命令面板 |
| `Ctrl+B` | 显示/隐藏侧栏 |
| `Ctrl+J` | 显示/隐藏底部控制台 |
| `Ctrl+I` | 显示/隐藏右侧面板 |
| `Ctrl+,` | 打开设置（服务商） |
| `Ctrl+1` … `Ctrl+6` | 切到 资源管理器 / 搜索 / Agent / 扩展 / 调试 / 设置 |
| `Ctrl+Enter` | 在对话输入框里发送 |
| `Esc` | 关闭菜单 / 命令面板 / 目录选择器 / 抽屉 |

macOS 上把 `Ctrl` 换成 `Cmd` 同样有效。

## 4. 为什么会这样

- **为什么左侧活动栏的悬停提示写着 `Ctrl+E`、`Ctrl+Shift+F` 之类，按了却没反应**：那些 `title` 是从 VS Code 的键位抄来的文案，实际只注册了 `Ctrl+1..6` 和上表那组。以本文的表格为准。
- **为什么命令面板提示 `Ctrl+P` 却要按 `Ctrl+K`**：输入框占位文案写的是 `Ctrl+P` / `Ctrl+Shift+P`，真实监听的是 `Ctrl+K`。这是已知文案不一致。
- **编辑器为什么是只读的**：后端只提供 `GET /api/workspace/read`（带扩展名白名单与 512KB 上限），没有对应的写入接口；所有写操作都被收束到 Agent 的 `file_write` / `file_edit`，目的是让写入必经审批闸门。所以编辑器的定位是「看」，不是「改」。
- **为什么能直接看文件却不能随便看**：`/api/workspace/read` 只接受文本类扩展名（`py/js/ts/tsx/html/css/md/json/yaml/toml/ini/xml/svg/csv/log/sql/sh/ps1/go/rs/java/c/cpp/cs/php/swift/kt/vue/svelte/astro` 等），二进制和 512KB 以上的文件会被拒绝，并提示改用 Agent 的 `file_read` 分片读。
- **两个界面怎么共存**：`/` 与 `/ide` 是两个页面壳，共用 `/api/chat`、`/api/agent/run`、`/api/sessions`、`/api/workspace`。所以你在 IDE 里建的会话，回到主界面也能看到。
- **审批策略为什么在 IDE 里也「看起来能选」**：它和主界面是同一个未实现项——只存浏览器本地（`localStorage`），不发后端，选「全部允许」也不会自动放行写操作。

## 5. 常见坑

- **点开文件没内容，只有「// 加载中…」**：读取失败会把这个占位换成「文件读取失败」并附后端原因。常见原因是扩展名不在白名单、文件超过 512KB、或路径含特殊字符。
- **点文件没反应**：文件树是单击打开文件、单击展开目录；树只加载一层，展开时才拉下一层。
- **以为 IDE 能改代码**：不能。中央区是只读视图，输入框在右侧对话面板里。
