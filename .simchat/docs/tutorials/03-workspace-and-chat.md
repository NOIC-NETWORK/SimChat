# 03 配置工作目录与第一次对话

> 本章属于「只使用」路径（A），前置：[02 接入第一个模型](02-first-model.md)。

## 1. 你会得到什么

顶部工作目录按钮从「选择工作目录」变成本地某个目录名，输入框解锁；发一句话能收到流式回复，刷新页面后这段对话还在左侧会话列表里。

```text
[📁 my-project]   ← 工作目录已设置
你：帮我看看这个目录里有哪些 py 文件？
SimChat：我目前没有读取目录的能力……（对话模式；Agent 模式见第 04 章）
```

## 2. 前置条件

- 服务商已可用（第 02 章验收通过）。
- 准备一个「你想让 AI 看/改的目录」。不要选整个磁盘根目录，也不要选系统目录。

## 3. 跟着做

1. 点顶部的工作目录按钮（默认文案「选择工作目录」）。如果输入框上方提示条写着「尚未选择工作目录，选择后即可开始对话。」，点它也会打开同一个选择器。
2. 在弹出的选择器里定位目录，三种方式任选：
   - 点上方的磁盘 / 根目录按钮（Windows 是 `C:\`、`D:\` 等，Linux/macOS 是 `/`）；
   - 双击列表里的文件夹逐级进入，「↑ 上一级」回退；
   - 在路径输入框直接粘贴绝对路径，点「打开」。
3. 当前目录会显示在顶部。确认无误后点「使用此目录」。
4. 预期：弹窗关闭，顶部按钮变成该目录名，输入框不再锁住。
5. 发一句「你好，你现在能看到什么？」确认能收到回复。左侧会新增一条会话，标题取你第一句话的前 30 个字符。
6. 用左侧「+」按钮开新对话，或在会话列表里点旧的切换。对话上下文按会话隔离，不会串。

### 清除或更换

- 换目录：再点顶部按钮，选一个新目录「使用此目录」即可。**已保存的会话不会跟着迁移**，它们只是历史记录，和目录无关。
- 清除：选择器左下「清除工作目录」→ 确认。清除后输入框立刻重新锁住，提示条回到「尚未选择工作目录」。

## 4. 为什么会这样

- **为什么没选目录就不让发消息**：工作目录是「对话与 Agent 的统一根」——Agent 的所有文件工具（`file_read`、`list_dir`、`glob`、`file_write`…）的相对路径都锚定在它上面。没有根目录，工具就没有安全边界，所以本体的门禁是「服务商可用 + 工作目录存在」两个条件同时满足才放行。前端把这两种缺失的提示分开显示：服务商缺失是「尚未配置可用的服务商，无法对话。」，目录缺失是「尚未选择工作目录，选择后即可开始对话。」，目录被删/改名则显示「工作目录不存在：…」。
- **存在哪**：写进 `.simchat/data/config.json` 的 `workspace` 段（含 `path` 与 `updated_at`）。这个文件同时存服务商配置，已被 `.gitignore` 忽略。
- **会话存在哪**：每个会话一个文件 `.simchat/data/sessions/<sid>.json`，结构是 `{id, title, mode, created_at, updated_at, messages, overrides}`。`mode` 是 `chat` 或 `agent`；一段会话只属于一种模式，前端在模式 A 里沿用模式 B 的 `session_id` 时，后端会另开一个新会话，避免两种上下文互相污染。
- **历史长度**：默认每个会话最多保留 40 条消息（`max_history=40`），超出后从最早的开始截断——注意是**丢弃**，不是摘要压缩。需要长上下文时在设置里调这个值。
- **流式是怎么来的**：浏览器 `fetch('/api/chat')` 读 SSE，事件依次是 `chat_started`（带回 `session_id`）→ 若干 `token`（增量文本）→ `final`（完整文本）或 `error`。会话落盘发生在流结束之后。
- **中断**：对话模式目前**没有单独的「停止生成」按钮**；刷新或关闭页面等于放弃这次请求，这条回复不会写进会话文件（只有 Agent 模式有停止，见第 04 章）。

## 5. 常见坑

- **能看到目录但「使用此目录」是灰的**：说明当前路径还没加载成功（顶部路径为空）。先点一个磁盘再往下走，或在路径框里输入后点「打开」。
- **目录里文件很多，只看得到一部分**：浏览列表最多显示 500 项，超过会提示「目录条目过多，仅显示前 500 项」。直接输入绝对路径仍然可用。
- **目录被移动/删除后对话报错**：提示条会显示「工作目录不存在：<路径>」，重新选一次即可。

## 6. 验收清单

- [ ] 顶部按钮显示的是具体目录名，而不是「选择工作目录」
- [ ] 能一句话说清「为什么没选目录不能发消息」
- [ ] 发一条消息收到流式回复，左侧会话列表出现新条目
- [ ] 刷新页面后这段对话还在
- [ ] 换一次工作目录，确认门禁与提示随之变化
