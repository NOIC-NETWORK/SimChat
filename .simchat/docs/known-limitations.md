# 已知限制清单

> 汇总自教程各章验收清单里「需要知道、但不是要你学会」的缺陷与未接线项。
> 教程 §6 只保留一行概括并指回本页；新增限制时，请同时更新对应章节的概括行。

| # | 限制 | 现状 / 影响 | 首次出现 |
|---|---|---|---|
| 1 | 审批策略下拉不生效 | Agent 实例的审批策略选择目前不改变实际拦截行为；`shell` 工具需要在权限里手工开启 | 04 |
| 2 | IDE 搜索与调试是占位 | 两个活动视图只有界面，未实现功能，不能使用 | 05 |
| 3 | 命令面板快捷键不一致 | 界面提示写 `Ctrl+P`，实际监听 `Ctrl+K` | 05 |
| 4 | `chat.mode` / `agent.completed` 未完整接线 | 声明 `chat.mode` 的包（如 `barry_galax`）在 Web 前端没有模式入口；`agent.completed` 钩子运行时不会派发 | 06 |
| 5 | automation 的 `event` 触发器不触发 | flow 可以通过校验、可以保存，但事件触发不会真的执行 | 10 |
| 6 | `file:write` 审批没有 Web 入口 | 在 Web 界面里无法完成这类审批，流程会停住 | 10 |
| 7 | MOD 子进程 traceback 不写入日志 | 沙箱里的异常不会出现在 `simchat.log`，只能从 `/api/console/*` 的 `items[].error` 与加载状态判断 | 11 |
| 8 | `cli --version` 与 `HOST_VERSION` 不同步 | 两处版本号可能不一致，以 `HOST_VERSION` 为准 | 12 |
