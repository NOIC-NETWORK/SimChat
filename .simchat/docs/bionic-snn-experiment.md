# Bionic：SNN 语言模型实验的可行性审查与最小验证方案

日期：2026-11-12

> 项目代号：**Bionic**  
> 性质：实验性研究，不进入 SimChat 稳定运行时。  
> 实验代码位置：`experiments/bionic/`，该目录已加入 `.gitignore`。  
> 技术术语：**SNN = Spiking Neural Network，脉冲神经网络**。

## 1. 审查结论

**实验立项有条件通过。SNN 可以构成自回归语言模型，但“脉冲神经网络天然比 Transformer 更适合大语言模型”目前没有足够依据。**

可以确认的是：

- SNN 的膜电位和脉冲状态可以随 token 序列递推，因此能够表示因果状态，并通过下一 token 分类头定义自回归语言模型。
- 直接训练、替代梯度、ANN-to-SNN 转换等技术提供了可实现的训练路径。
- 这条路线适合研究**事件驱动计算、多时标状态、稀疏激活和低功耗序列建模**。

目前不能确认的是：

- “Transformer 没有前途”不是本实验可以预设的结论，也不是研究 SNN 的必要理由。
- SNN 的生物启发不等于生物真实性，更不自动产生类人理解、意识或长期记忆。
- 脉冲稀疏不自动等于低能耗。普通 GPU 往往仍以稠密张量模拟脉冲，额外仿真步数反而可能增加成本。
- 小规模 SNN 能训练，不等于它能按当前主流大模型的规模稳定训练和提供服务。

建议把研究命题收敛为：

> **构建不依赖注意力的因果脉冲语言模型，验证其在语言建模质量、训练稳定性、推理延迟和实测能耗上是否存在可复现的优势。**

这个命题可以被实验支持，也可以被实验否定，两条结果都有价值。

## 2. 原始思路需要修正的地方

| 原始想法 | 需要修正之处 | 可执行的改写 |
|---|---|---|
| Transformer 没有前途 | 宏观判断不能直接指导模型设计 | 在相同数据、词表和预算下对比 SNN、循环网络与 Transformer |
| 训练 SNN 做 LLM | 神经元模型不等于完整语言模型 | 明确 token 编码、因果状态、词表读出头和自回归训练目标 |
| 脉冲是离散的，所以推理更便宜 | 普通硬件上的脉冲通常仍是稠密模拟，时间步还会增加开销 | 分开统计理论脉冲事件数与实际延迟、显存、能耗 |
| SNN 更接近大脑，所以能力更强 | LIF 等模型是高度简化的神经动力学，能力不能由“仿生”推出 | 把生物启发作为结构来源，把语言指标作为能力证据 |
| 取名 Bionic | 名称不证明生物合理性或技术原创性 | 保留为项目代号，技术描述使用准确的 SNN 结构名称 |

核心原则不变：**先证明一个具体优势，再讨论替代通用架构。**

## 3. SNN 怎样构成语言模型

### 3.1 从脉冲神经元到下一 token 分布

以简化的 LIF（Leaky Integrate-and-Fire）神经元为例：

$u_{n,\tau}=\beta u_{n,\tau-1}+i_{n,\tau}-r_{n,\tau}$

$s_{n,\tau}=\mathbb{1}[u_{n,\tau}\geq\theta]$

其中：

- `n` 是 token 位置；
- `τ` 是该 token 内部的仿真时间步；
- `u` 是膜电位，`s` 是脉冲；
- `β` 是泄漏/保留系数，`θ` 是发放阈值，`r` 是发放后的复位项。

语言模型不一定让每个神经元直接输出词表概率。更实用的做法是读取膜电位、平均发放率或两者的组合，再接线性词表头：

\[
p(x_n\mid x_{<n})=\operatorname{softmax}(W r_n+b)
\]

这样就有了明确的自回归训练目标：下一 token 交叉熵。SNN 替代的是语言模型的**时序表示骨干**，而不是取消分词器、输出头和概率训练目标。

### 3.2 token 步与仿真步必须分开

这是整个实验最容易混淆的变量：

- **token 步**：文本序列走到下一个 token；
- **仿真步**：为处理当前 token，神经元状态继续演化 `T` 次。

常见输入方式包括把嵌入电流重复注入 `T` 步、按时间调制输入，或直接采用 `T = 1`。它们不是等价实现：

- `T > 1` 可能改善脉冲信息表达，但会增加串行计算和训练显存；
- `T = 1` 成本低，但行为更接近带二值激活的循环网络，不能宣称利用了丰富的时间编码；
- 输出发放率需要多个仿真步才稳定，而膜电位读出通常更直接。

因此，`T` 必须作为核心自变量报告，不能藏在实现细节里。

## 4. 建议的 Bionic 最小架构

### 4.1 结构

```text
历史 tokens
    │
    ▼
Token Embedding（转为输入电流或连续驱动）
    │
    ▼
因果脉冲块 × L
  ├─ 线性/卷积投影
  ├─ LIF 或参数化 LIF 神经元
  ├─ 多时标膜电位状态
  └─ 残差连接与状态复位
    │
    ▼
膜电位 / 发放率读出
    │
    ▼
线性词表头 + Softmax
    │
    ▼
p(next_token | previous_tokens)
```

第一版建议采用**脉冲骨干 + 稠密词表读出头**。这是合法的 SNN 语言模型实验，但必须如实称为混合实现，不能宣称所有计算都已脉冲化。

### 4.2 第一版的约束

- 不使用注意力；Transformer 只作为对照组。
- 使用直接训练和替代梯度，不把 ANN-to-SNN 转换作为第一版依赖。
- 使用膜电位读出，避免第一版同时解决低发放率与输出量化两个问题。
- 优先采用可学习或多时标的膜时间常数，但保持公式和状态转移白盒可检查。
- 每个文档边界显式复位脉冲状态；跨训练 chunk 携带状态时，必须同时保持因果顺序并正确截断反向传播。

### 4.3 训练必须面对的难点

1. **不可导脉冲函数**：使用替代梯度可以训练，但它是优化近似，不是真实导数。
2. **长序列反向传播**：反向图同时沿 token 长度和仿真步展开，显存与计算都会增长。
3. **死亡神经元与脉冲饱和**：阈值过高可能完全不发放，过低则退化为持续脉冲并破坏稀疏性。
4. **训练并行性**：循环状态和多个仿真步会削弱 Transformer 擅长的高度并行训练优势。
5. **长上下文瓶颈**：固定大小的循环状态虽然不占随序列增长的 KV cache，但并不保证能记住远程信息。

## 5. 最小可行实验（MVP）

### 5.1 对照组

| 组别 | 模型 | 用途 |
|---|---|---|
| A | n-gram | 提供最低复杂度基线 |
| B | GRU 语言模型 | 成熟的非注意力循环基线 |
| C | 与 Bionic 同拓扑的连续循环网络 | 隔离“脉冲化”本身带来的影响 |
| D | Bionic SNN | 主实验 |
| E | 同量级 Transformer | 对比质量、训练并行性和推理成本 |
| F | D 的消融版本 | 改变仿真步、时间常数、读出方式与发放正则 |

C 组很重要。只和 Transformer 比较，无法判断收益来自循环结构、特定归纳偏置还是脉冲机制。

### 5.2 实验顺序

**M0：学习正确性**

- 先让模型过拟合一个极小批次，确认损失确实下降；
- 检查脉冲状态是否严格因果，文档之间是否正确复位；
- 检查膜电位、发放率、梯度和词表概率是否出现 NaN 或饱和；
- 验证训练 chunk 与逐 token 解码时的状态转移一致。

**M1：小规模语言建模**

- 所有模型共享分词器、词表、训练 token、数据顺序和评估集；
- 用下一 token 交叉熵直接训练 Bionic；
- 对 `T = 1 / 2 / 4` 等小规模设置做消融，不预设步数越多越好；
- 至少运行 3 个随机种子，报告均值与波动；
- 同时比较训练集和留出集，避免把背诵误判为泛化。

**M2：效率与稀疏性**

- 分别报告参数量、实际训练计算量、单 token 延迟和峰值显存；
- 统计每层平均发放率、有效脉冲事件数和不同 `T` 下的成本；
- 在普通 GPU 上测量真实吞吐，不把理论上的“少做乘加”直接写成实测加速；
- 将 embedding、词表头、损失计算和数据传输计入总成本，避免只测脉冲骨干；
- 有条件时再测能耗，没有测量就明确写“未实测”。

**M3：扩展与硬件验证**

只有 M1 表明模型能稳定学习、M2 表明存在明确质量或效率价值后，才扩大语料、隐藏维度和层数，并评估神经形态硬件。第一阶段不需要先购买或适配专用硬件。

### 5.3 必报指标

| 维度 | 指标 |
|---|---|
| 语言建模 | 留出集 NLL、困惑度、训练/验证差距 |
| 稳定性 | 多随机种子波动、梯度异常、死亡神经元比例 |
| 脉冲行为 | 各层发放率、膜电位分布、脉冲事件总数 |
| 时间步 | 不同 `T` 下的质量、显存、延迟和吞吐 |
| 推理效率 | tokens/s、P50/P95 单 token 延迟、峰值内存 |
| 能耗 | 整链路实测能耗；无法实测时不做节能结论 |
| 长序列 | 远程依赖任务、长文一致性、状态遗忘情况 |
| 生成 | 重复率、未见主题表现、下游任务与人工检查 |

困惑度只能证明概率预测的一部分，不能单独推出推理能力或生物智能。

## 6. 公平比较规则

1. **同数据**：相同训练 token 和评估划分，不让某个模型额外看数据。
2. **同词表**：困惑度比较必须基于同一分词器和词表。
3. **多口径报告**：分别给出相近参数量、相近训练计算量和相近推理延迟的结果，不混称为一次“公平比较”。
4. **计入仿真步**：SNN 的 `T` 步不能从 FLOPs、延迟和能耗核算中消失。
5. **计入输出头**：大词表线性层和 Softmax 可能占据大量稠密计算，不能被脉冲稀疏叙事忽略。
6. **计入状态**：循环状态不占 KV cache 是优势，但固定状态造成的信息损失也必须通过长序列实验呈现。
7. **理论值与实测值分开**：脉冲事件数、GPU 墙钟时间、能耗计测量是三类不同证据。

## 7. 通过与止损条件

### 7.1 支持继续扩展的最低证据

至少需要看到：

1. Bionic 能跨多个随机种子稳定训练，留出集表现不是偶然结果；
2. 相比同拓扑连续循环网络，可以明确说明脉冲化带来了什么收益，或者造成了多大质量损失；
3. 把全部仿真步和稠密输出头计入后，仍在至少一个预先声明的维度上有优势，例如数据效率、状态大小、实际延迟或实测能耗；
4. 优势不是只存在于单一语料、单一 `T` 或单一超参数点；
5. 长序列评测没有暴露出与目标用途不相容的状态遗忘。

这些证据只支持“该 SNN 设计在该设置下有效”，不能推出“SNN 全面优于 Transformer”。

### 7.2 应停止当前方案并调整的信号

- 只有理论脉冲事件数下降，实际 GPU 延迟和能耗持续上升；
- 必须不断增加 `T` 才能训练，而成本增长完全吞掉收益；
- 大量神经元不发放，或持续满发放，且调阈值只能短暂缓解；
- 同拓扑连续网络稳定优于 SNN，脉冲化没有带来任何被测优势；
- 词表头和 embedding 占据主要成本，仅优化脉冲骨干无法改变整链路表现；
- 固定脉冲状态无法保留任务所需的远程信息；
- 优势只在单一随机种子或单一数据集上出现。

否定结果应归档为对编码、神经元参数、读出方式或训练目标的约束证据，而不是扩大规模硬冲。

## 8. 新颖性与“Bionic”表述边界

SNN 用于 NLP、脉冲循环网络、脉冲注意力以及 SNN 与 Transformer 结合，均已有研究积累。不能把“用 SNN 做语言模型”本身声明为首次提出。

Bionic 若要形成独立贡献，应落在具体、可复现的机制上，例如：

- 面向自回归文本的非注意力脉冲状态结构；
- token 步与仿真步之间的新型编码或成本分配；
- 多时标膜状态对远程语言依赖的可测改善；
- 低发放率下仍保持词表读出质量的方法；
- 在固定延迟或固定能耗预算下的质量—稀疏性权衡；
- 能在目标硬件上端到端运行，而非只在模拟器里理论节能的脉冲语言模型。

同时需要克制“仿生”表述：

- LIF、替代梯度和稠密 embedding 都是对生物神经系统的工程抽象；
- 使用脉冲不等于复现大脑的学习规则；
- 除非另有神经科学证据，应使用“受神经元脉冲启发”，而不是“模拟人脑”或“具备生物智能”。

正式宣称原创性之前仍需单独做文献检索；本文只审查技术逻辑与实验设计。

## 9. 项目边界

- Bionic 是独立实验，不修改 SimChat 的稳定模型服务商、AgentLoop 或记忆库核心逻辑。
- 实验代码、权重、运行输出和数据统一放在 `experiments/bionic/`，不提交 Git。
- 第一阶段不追求通用对话产品，不接生产接口，不做大规模训练。
- 第一阶段只回答一个问题：**因果 SNN 能否稳定学习语言建模，并在完整成本核算后呈现至少一个真实优势。**

---

## 10. 最终意见

**术语明确后，思路作为研究项目仍然成立，SNN 的事件驱动和时序状态也与“Bionic”这个代号相契合。**

最稳妥的实施路线是：先做一个**无注意力、直接训练、膜电位读出的小规模自回归 SNN**，用同拓扑连续网络、GRU 和 Transformer 做对照，先验证学习正确性，再验证脉冲化的净收益。

当前可以通过的是实验方案，不是“SNN 已经能够替代 Transformer”的结论。是否值得扩展到“大语言模型”，必须由质量、时间步成本、长序列能力和整链路能效共同决定。
